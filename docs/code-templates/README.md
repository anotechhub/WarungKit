# WarungKit Visual Code Templates

File di folder ini bukan untuk dipakai otomatis. Ini reference untuk Claude Code saat mengintegrasikan visual upgrade.

- `product-assets.example.ts`: mapping product slug ke asset image.
- `feature-assets.example.ts`: mapping feature card ke icon image.
- `ScrollReveal.example.tsx`: component animasi reveal berbasis IntersectionObserver.
- `warungkit-motion.example.css`: CSS motion premium dan hover image.

Claude Code boleh menyalin/menyesuaikan isi file ini ke lokasi yang paling cocok di `apps/web/src`.
